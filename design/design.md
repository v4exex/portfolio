# Portfolio Design Guide

`index.html`의 현재 디자인을 정리한 문서. 레퍼런스: [blog.maximeheckel.com](https://blog.maximeheckel.com/) (`design/blog.maximeheckel.com.jpeg`).
새 UI를 만들거나 수정할 때 이 규칙을 따른다.

## 1. 컨셉

- **다크 + 미니멀 + 에디토리얼.** 화면 상단에만 강한 파란 빛과 파티클 비주얼을 두고, 아래는 거의 검은 배경에 얇은 선으로 된 목록만 둔다.
- 장식은 히어로 영역에 몰아주고, 본문 영역은 조용하게 유지한다.
- 좁은 단일 칼럼(640px)으로 글 읽는 느낌을 준다.

## 2. 색상 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#080a10` | 페이지 배경 |
| `--text` | `#f2f4fa` | 제목, 강조 텍스트 |
| `--muted` | `#a3abc0` | 소개문 본문 |
| `--dim` | `#6b7388` | 보조 정보 (스택, 분류) |
| `--line` | `rgba(255,255,255,.07)` | 격자, 연도 구분선 |
| `--blue` | `#0a60ff` | 히어로 파란 글로우 |

- 행 구분선: `rgba(255,255,255,.045)`, 행 hover 배경: `rgba(255,255,255,.04)`
- 포인트 컬러는 파란색 하나뿐이다. 그라데이션 텍스트, 다른 강조색은 쓰지 않는다.
- 다크 단일 테마. 라이트 모드는 지원하지 않는다.

## 3. 타이포그래피

- 본문: `Inter`, `Noto Sans KR`, system-ui
- 숫자·연도·태그 등 메타 정보: `JetBrains Mono`

| 요소 | 크기 | 굵기 | 비고 |
|---|---|---|---|
| 히어로 제목 `h1` | 1.02rem | 600 | line-height 1.35, letter-spacing -.01em |
| 소개문 | .78rem | 400 | line-height 1.7, `--muted` |
| 소개문 강조 `b` | - | 600 | `--text` |
| 소개문 강조 `em` | - | italic | `#c9d0e4` |
| 연도 라벨 | .68rem | 500 | mono, 흰색 |
| 행 제목 | .88rem | 500 | `#dfe4f2`, hover 시 `#fff` |
| 행 설명 | .74rem | 400 | `--dim` |
| 행 우측 분류 | .68rem | 400 | mono, `--dim` |
| 행 기간(날짜) | .74rem | 500 | mono, `#9db8ff`(옅은 파랑), hover 시 `#fff` |

글자는 전반적으로 작게 쓴다. 큰 제목으로 시선을 끌지 않고 비주얼이 그 역할을 한다.

## 4. 레이아웃

- 콘텐츠 최대 너비 `--maxw: 640px`, 중앙 정렬, 좌우 패딩 20px
- 순서: 파티클 비주얼(높이 330px, 상단 여백 70px) → 2단 소개문 → 연도별 목록 → 푸터
- 소개문: 2열 그리드, gap 28px. 560px 이하에서는 1열.
- 목록 영역 상단 여백 76px, 하단 패딩 140px
- 행은 좌우 -8px 마진 + 8px 패딩으로 hover 배경이 선 밖으로 살짝 나온다.

## 5. 컴포넌트

### 플로팅 내비게이션
- `position: fixed`, 상단 14px, 가로 중앙 알약 형태 (radius 14px)
- 배경 `rgba(40,70,160,.35)` + 테두리 `rgba(255,255,255,.12)` + `backdrop-filter: blur(16px)`
- 구성: 로고 아이콘(`</>` 형태 SVG, 20px, stroke 1.6) | 구분선 | Index · Projects · Contact
- 링크: .78rem / 600, hover 시 `rgba(255,255,255,.14)` 배경
- 메뉴는 3개로 유지한다. 새 메뉴는 꼭 필요할 때만 추가.

### 히어로 배경
- `.blue`: 좌상단(0 0)에서 퍼지는 파란 radial-gradient + 상단 중앙 보조 글로우. 아래쪽으로 마스크 페이드아웃. 높이 760px.
- `.grid`: 36px 간격 격자선. 좌상단 기준 radial 마스크로 중심만 보이게 한다.
- `.grid.faint`: 우상단에 아주 옅은(.05) 격자를 하나 더 둔다.

### 파티클 ∞ (canvas)
- 7000개 흰색 점으로 렘니스케이트(∞) 곡선을 그린다. 캔버스 1720×660, 표시 폭 860px.
- 왼쪽은 두껍고 밝게, 오른쪽 아래는 얇고 흩어지듯 사라진다.
- 천천히 회전·흔들리는 애니메이션. `prefers-reduced-motion`이면 정지.

### 연도별 목록
- 연도 블록: 상단 1px 선 + 모노 폰트 연도 라벨 (최신 연도가 위)
- 행: `기간(132px 고정 열, 파란빛 mono)` + `제목/스택` + `분류` 3열. 기간이 눈에 띄도록 본문 회색이 아닌 옅은 파랑을 쓴다. 상단 1px 얇은 선으로 구분. 560px 이하에서는 기간이 제목 위 한 줄로 올라간다.
- 카드·그림자·둥근 박스는 쓰지 않는다. 선과 hover 배경만 사용.

### 기술 스택 (Tech Stack)
- 연도 목록 맨 위(2026 위)에 `Tech Stack` 블록으로 둔다. Frontend / Backend & Database / Tools 3그룹.
- 그룹 제목은 날짜 열과 같은 132px 열에 맞추고, 오른쪽에 44px 아이콘 타일을 나열한다.
- 타일: 52px 정사각형, 둥근 14px, 어두운 그라데이션 + 상단 브랜드색 은은한 빛 + 얇은 테두리. 아이콘은 실제 브랜드 로고(Simple Icons, CC0)를 인라인 SVG로 넣고 `--c` 브랜드색으로 칠한다.
- hover: 5px 위로 + 아이콘 확대 + 브랜드색 테두리·글로우 + 아래에 이름 툴팁. 이 타일에 한해 글로우(그림자)를 허용하고, 브랜드색도 이 타일에서만 예외로 허용한다.
- 아이콘은 인라인 SVG 또는 텍스트 모노그램만 사용(외부 이미지 금지).

### 푸터
- 좌: `© 연도 이름`, 우: 이메일 링크. mono .7rem, `--dim`.

## 6. 모션

- 스크롤 진입 시 `.rv` 요소가 `opacity 0→1`, `translateY(12px)→0` (0.7s)
- hover 전환은 .2s
- 파티클은 상시 애니메이션
- `prefers-reduced-motion: reduce`이면 전환·스크롤 스무딩·파티클 움직임을 모두 끈다.

## 7. 반응형

- 560px 이하: 소개문 1열, 캔버스 표시 폭 640px
- 가로 스크롤이 생기지 않도록 `body { overflow-x: hidden }`

## 8. 하지 말 것

- 파란색 외의 강조색, 그라데이션 텍스트 추가
- 카드형 박스, 그림자, 큰 둥근 모서리 사용 (기술 스택 타일 hover 글로우만 예외)
- 본문 영역에 배경 장식 추가 (장식은 히어로에만)
- 외부 이미지·라이브러리 추가 (현재는 HTML/CSS/JS + Google Fonts만 사용)
- `index.html`에 `<style>` 태그나 `style` 속성으로 CSS 작성 (9번 참고)
- 내비게이션 메뉴를 과도하게 늘리기

## 9. 코드 규칙

- **HTML 안에 CSS를 직접 쓰지 않는다.** `<style>` 태그와 `style="..."` 속성을 모두 금지한다.
- 모든 스타일은 별도 파일 `css/style.css`에 작성하고, `index.html`에서는 `<link rel="stylesheet" href="css/style.css">`로 불러온다.
- 색상·간격 같은 공통 값은 `css/style.css`의 `:root` 토큰으로 관리한다.
- 스크립트도 인라인으로 쓰지 않고 `js/main.js`에 작성해 `<script src="js/main.js" defer></script>`로 불러온다.
- JS로 값을 바꿔야 할 때는 인라인 스타일 대신 클래스 토글(예: `.rv` → `.in`)을 사용한다.

## 10. 파일 구조

```
portfolio/
├─ index.html        마크업만
├─ css/style.css     모든 스타일
├─ js/main.js        모든 스크립트 (파티클, 스크롤 reveal)
└─ design/           디자인 문서와 레퍼런스 이미지
```
